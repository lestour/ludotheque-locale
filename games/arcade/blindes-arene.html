Règles

  • Détruisez tous les blindés d’une vague pour faire apparaître la suivante.
  • Les murs indestructibles bloquent les tirs ; les caisses brunes peuvent être détruites.
  • Les capsules accordent réparation, cadence rapide, obus ricochets ou bouclier.
  • Les ennemis éclaireurs contournent les murs, les lourds encaissent davantage et les artilleurs anticipent vos déplacements.
  • Chaque arène est testée pour conserver un chemin entre les zones de départ.
